## Store listing tab

**Name** (taken from the manifest): Clownmeter

**Summary** (max 132 characters; also from the manifest's `description`):

> Rates X and Threads posts for bait, trolling, plain dumbness and AI slop.

**Description:**

```
Clownmeter adds small score badges next to posts on X (Twitter) and Threads, so you can spot rage bait, trolls, nonsense and AI-generated filler at a glance.

WHAT IT RATES (pick any in the popup)
🎣 Bait – engagement and rage farming, clickbait hooks, flamebait
🧌 Troll – bad-faith provocation, dunking, deliberate misrepresentation
🤡 Dumb – plainly wrong or incoherent reasoning (not spelling, not opinions you disagree with)
🤖 AI slop – generic AI-sounding filler: stock phrases, emoji-bullet listicles, "Thoughts? 👇"

Each category gets its own 0–100 badge, colored green to red. Click a badge to see why the post got that score.

HOW IT WORKS
• Bring your own API key: Google Gemini (a free key is enough) and/or Groq as a fallback.
• Posts are rated as you scroll, or only when you click, your choice.
• Posts with images or video are skipped by default, because the AI only sees text.
• Ratings are cached, so a post is never rated twice.
• Built-in rate limiting: when Gemini's free quota runs out, Groq takes over automatically.

PRIVACY
Post text is sent only to the AI provider whose key you enter. Your keys and settings stay in your browser. No accounts, no analytics, no tracking, and nothing is sent to the developer.

GETTING STARTED
1. Install. The options page opens automatically.
2. Paste a Gemini API key (free from Google AI Studio), press Test, then Save.
3. Open X or Threads and scroll.

Open source: https://github.com/abdullakarimov/clownmeter
```

## Privacy practices tab

**Single purpose description:**

> Clownmeter rates posts on X and Threads for bait, trolling, dumbness and AI-generated filler, by sending post text to an AI model chosen by the user and showing the resulting scores as badges next to each post.

**Permission justifications:**

| Permission | Justification |
|---|---|
| `storage` | Saves the user's settings (enabled categories, toggles), their AI provider API keys and models, request counters for rate limiting, and cached ratings so the same post isn't rated twice. |
| Host permission: `https://x.com/*`, `https://twitter.com/*` | The content script reads post text on X to rate it and shows the score badges next to each post. |
| Host permission: `https://www.threads.com/*`, `https://www.threads.net/*` | The content script reads post text on Threads to rate it and shows the score badges next to each post. |
| Host permission: `https://generativelanguage.googleapis.com/*` | Sends post text to the Google Gemini API with the user's own API key to get the ratings. |
| Host permission: `https://api.groq.com/*` | Sends post text to the Groq API with the user's own API key, as a fallback when Gemini is rate-limited or unavailable. |

**Are you using remote code?** No. All JavaScript is included in the package.

**Data usage**: what the extension collects. Tick:

- ☑ **Website content**: the text of posts on X/Threads is sent to the user's chosen AI provider to produce the ratings.

Leave everything else unticked. The extension does not collect personally identifiable information, health, financial, authentication, personal communications, location, web history or user activity. API keys the user enters are stored locally and only sent to their own provider; they are never collected by the developer.

**Certifications**: tick all three:

- ☑ I do not sell or transfer user data to third parties, outside of the approved use cases
- ☑ I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- ☑ I do not use or transfer user data to determine creditworthiness or for lending purposes
